# Side Glance Homebrew Tap

Official Homebrew formulae for [Side Glance](https://github.com/AndrewUlloa/side-glance),
a local-first attention layer for coding-agent CLIs.

```bash
brew install AndrewUlloa/tap/side-glance
side-glance init
```

Side Glance is currently a beta. The formula installs immutable, checksummed
release artifacts for macOS and glibc-based Linux. Intel macOS support remains
experimental.
